# БП — макет новых процессов

Интерактивный макет для системы **«Бюро Пропусков»** (АО НК «КазМунайГаз»).
Отражает два новых процесса: самостоятельное фото посетителя в электронном пропуске
и сверку личности охранником по QR-коду.

Основной проект: `../bp-ui` (ветка `server31`) — Angular 13 + ng-zorro-antd.
Макет сделан в его стилистике: primary `#02AEF0`, тёмно-синий `#233862`,
шрифт Inter, компоненты Ant Design, скругления 7–8 px.

## Стек

React 19 + TypeScript + Vite, Ant Design 6 (React-аналог ng-zorro),
react-router-dom (HashRouter), qrcode.react.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4300, слушает и внешний IP — можно открыть с телефона
```

Камера (`getUserMedia`) в мобильных браузерах работает только по `https` или на
`localhost`. Для показа с телефона поднимите туннель (`npx localtunnel --port 4300`)
либо воспользуйтесь кнопкой «Файлом» в модалке съёмки.

## Сценарии

| Маршрут | Шаг | Что показывает |
|---|---|---|
| `#/` | — | Индекс сценариев |
| `#/mail` | 1 | Письмо с электронным пропуском, которое приходит посетителю |
| `#/pass/4527` | 2 | Пропуск на телефоне посетителя: кнопка **«Снять на фото»** и QR внизу |
| `#/guard` | 3 | Пост охраны: сканирование QR камерой телефона |
| `#/guard/pass/4527` | 4 | Пропуск у охранника: селфи + скан удостоверения, сверка, «Пропустить / Отказать» |

Фото, снятое на шаге 2, появляется у охранника на шаге 4. В макете обмен идёт через
`localStorage` (`src/data/mock.ts`) — в боевой системе это бэкенд и SignalR-хаб
`hubs/security`.

## Публикация на GitHub Pages

Всё уже настроено:

- `vite.config.ts` — `base: './'`, поэтому сборка работает в подпапке
  `https://<user>.github.io/<repo>/` без правок;
- роутинг на **HashRouter** — GitHub Pages не умеет отдавать `index.html`
  на произвольный путь, поэтому прямые ссылки вида `#/guard/pass/4527` не ломаются;
- `public/.nojekyll` — чтобы Pages не прогонял сборку через Jekyll;
- `.github/workflows/deploy.yml` — сборка и деплой при пуше в `main`.

Что сделать один раз после создания репозитория:

1. запушить проект в ветку `main`;
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Дальше каждый пуш в `main` обновляет опубликованный макет.

> Репозиторий рассчитан на то, что его корень — эта папка (`bp-mockup`).
> Если корнем будет папка уровнем выше, в workflow нужно добавить
> `defaults.run.working-directory: bp-mockup` и поправить `path: dist` на `bp-mockup/dist`.

## Структура

```
src/
├── components/
│   ├── PassDocument.tsx    тело пропуска (поля повторяют печатную форму
│   │                       views/terminal/print-terminal основного проекта)
│   ├── CameraCapture.tsx   съёмка селфи, аналог views/terminal/image-capture
│   └── PhoneFrame.tsx      рамка телефона — только для демонстрации на десктопе
├── pages/                  четыре экрана процесса + индекс
├── data/mock.ts            мок-данные пропуска (по образцу TerminalDto) и состояние демо
├── assets/                 логотипы и шрифт Inter из основного проекта
└── theme.ts                токены Ant Design под тему основного проекта
```

Скан удостоверения — рисованный плейсхолдер `src/assets/img/id-card-mock.svg`,
персональных данных в макете нет.
